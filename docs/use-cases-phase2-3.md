# ユースケース フェーズ2–3 — 送出・入力拡張

全体の一覧は [use-cases.md](use-cases.md)。いずれも登録（フェーズ1）の後に行う。OCRとAPIはどちらを先にしてもよい。

## UC-11 ARIM RDE へ送出する

- だれが: 実験者（送出を担当する実験者を含む）
- すること: 送る実験データを選び、データセットの情報（課題番号など）を添えて送出
- 前提: 送出したあとも、正式な記録は本システムのまま
- 確認したいこと:
  - 送出のタイミング（その日のうち、週に1度、論文の前など）
  - 1回の送出でまとめる単位（データセット）の決め方
  - 送出に失敗したとき、現場でどう分かるとよいか

## UC-12 OCR で登録する

- だれが: 実験者
- すること: 装置のパネルや紙のノートを撮影し、読み取り結果を確認・補正して登録
- 確認したいこと:
  - 撮影する対象は装置のパネルか、紙のノートか、両方か
  - 読み取り結果は実験者が必ず確認する前提でよいか

## UC-13 API で登録する

- だれが: 連携する外部システム（実験者は間接的に関わる）
- すること: API から実験データを登録
- 前提: 権限や訂正の決まりは手入力と同じ
- 確認したいこと:
  - 連携したい装置やソフトがあるか、その優先度
  - API から登録した場合、登録した実験者をどう特定するか
