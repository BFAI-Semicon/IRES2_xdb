## ロール

| ロール         | だれか                 | できること                                                             |
| -------------- | ---------------------- | ---------------------------------------------------------------------- |
| ユーザー       | 装置の前で記録を残す人 | 試料の作成・編集、実験データの登録、自分が登録した実験データの訂正     |
| 装置担当       | ユーザーの役割         | 全装置の固有情報欄を定義、装置台帳を管理。値の入力はユーザーとして行う |
| グループ担当   | ユーザーの役割         | グループのメンバーの追加・除外、課題の登録、グループの削除             |
| システム管理者 | 本システムの運用者     | ユーザー・グループ・試料・実験データの削除                             |

ユーザーではない装置担当・グループ担当はいない。システム管理者はユーザーではなく、記録は残さない。

グループの役割は使いやすさを優先し、グループ担当とユーザーの 2 つに限る。ARIM RDE へ送出するときは、グループ担当を研究チーム管理者（OWNER）、ユーザーを研究チームメンバ（MEMBER）に写す。ARIM の管理者代理・データ登録代行者・データ閲覧者は本システムでは持たず、必要なら RDE 側で設定する。登録の代行は、実験データのデータ所有者を登録者と別にすることで表す。

「データ所有者」「試料管理者」は ARIM RDE と同じく属性であり、役割ではない。権限は付かない。DICE ID はユーザーの任意項目で、登録時に未取得でもよい。

## グループ

- ユーザーが属する、本システムのまとまり。大学の研究室や企業の部署を想定
- 試料が属する範囲であり、試料名が一意である範囲
- 実験データはグループを持たない（属するグループは試料から決まる）。実験データが指す試料は 1 つ
- 装置はグループに属さない。ARIM RDE の所属（organization）とは別
- ユーザーは複数のグループに属せる
- グループは ARIM の課題（課題番号・期間・装置ごとのデータセット）を 0 個以上持つ。課題は年度ごとの利用申請で変わるため、グループ = 課題にはしない
- 実験データは課題に属さない。送出時に、試料のグループが持つ課題からデータセットを選ぶ。送れた事実は送出記録に残る

## 対象外

装置予約、稼働見える化、映像化・画像解析、施設、工程、ユーザーによる実験データの削除。

## 確認

- [ ] 1操作=1実験データ。失敗・中断も登録し削除しない
- [ ] 1実験データ=1試料
- [ ] グループの役割はグループ担当とユーザーの2つだけ
- [ ] データ所有者・試料管理者は属性で、権限は付かない
- [ ] DICE IDはユーザーが後から追記する
- [ ] 正本は本システム。ARIM RDEは後から送る先
- [ ] 固有情報欄は装置担当が定義、ユーザーは値を入れる
- [ ] 実験データの訂正は登録者のみ
- [ ] 試料編集は作成者とその試料を使ったユーザー
- [ ] 削除は表示から隠すだけで記録は残る（ユーザー・グループ・試料・実験データ）
