## ロール

| ロール   | だれか                 | できること                                 |
| -------- | ---------------------- | ------------------------------------------ |
| 実験者   | 装置の前で記録を残す人 | 試料作成、実験データの登録・自分の件の訂正 |
| 装置担当 | 実験者の役割           | 全装置の固有情報欄を定義（値は入れない）   |

実験者ではない装置担当はいない。

## グループ

| 項目     | 説明                                                             |
| -------- | ---------------------------------------------------------------- |
| グループ | ユーザーの所属先。試料が属する範囲であり、試料名が一意である範囲 |

- 大学の研究室や企業の部署を想定
- 実験データはグループを持たない（属するグループは試料から決まる）
- 装置の所属先ではない。ARIM RDE の所属（organization）とは別
- 実験者は複数グループに所属可能

## 対象外

装置予約、稼働見える化、映像化・画像解析、施設、工程、実験データの削除。
