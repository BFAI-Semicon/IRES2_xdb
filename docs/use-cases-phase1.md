# ユースケース フェーズ1 — 本システムへの登録

全体の一覧は [use-cases.md](use-cases.md)。ここでは、ユーザーが装置の前で実験データを本システムに残すまでの場面を並べる。

## このフェーズに共通すること

- 本システムに登録した実験データが正式な記録（正本）
- 登録した実験データは削除できない。誤りは訂正して直す
- 訂正後は、最新の内容が正式な記録。前の内容は訂正履歴に残る
- 試料は1つのグループに属する。実験データは試料を1つ指す
- 固有情報、データファイル、添付ファイル、説明は空欄でも登録可
- 実験データのデータ所有者は既定で登録者、試料の試料管理者は既定で作成者。どちらも別のユーザーに変えられ、権限は付かない
- DICE ID・所属はユーザーの任意項目。未取得でも登録できる。ARIM RDE への送出時に必要になる

## UC-01 グループに所属する

- だれが: ユーザー
- すること: 1つ以上のグループに所属し、試料作成時にグループを選択
- 確認したいこと:
  - グループの単位は研究室か、部署か、別の区切りか
  - メンバーの追加や除外をだれが行うか。仮説: 「グループ担当」の役割を持つユーザーが行い、各グループに 1 人以上置く
    - グループを作ったユーザーが最初の担当。最後の 1 人は除外も辞退もできない（退職・卒業時は先に後任を指名）

## UC-02 試料を作る

- だれが: ユーザー
- すること: グループを選び、試料名を付けて試料を作成。化学式・組成式・分子式、参考 URL、タグ、試料の説明は空欄でも可。試料管理者は既定で自分
- 前提: 同一グループ内における試料名はユニーク
- 確認したいこと:
  - 現場で使っている試料名の付け方
  - 組成は試料作成時に必須か、後から入力でもよいか
  - 試料管理者を作成者以外にする場面があるか（学生が作り、教員が管理者など）

## UC-03 試料の内容を直す

- だれが: その試料を作ったユーザー、またはその試料を使って実験データを登録したユーザー
- すること: 試料の組成や名称などの誤りを訂正
- 確認したいこと:
  - 「作った人と使った人だけが直せる」で現場は足りるか
  - 同じグループの他のユーザーにも訂正を許したい場面があるか

## UC-04 装置を台帳に登録する

- だれが: 装置担当
- すること: 製造装置か検査装置かを決めて、装置を台帳に登録
- 前提: 台帳はシステム全体で1つ。1台の装置は主な用途でどちらか一方の種別
- 確認したいこと:
  - 装置の追加、名称変更、使用終了を装置担当が行う形で問題ないか
  - 現場で通じる装置の呼び名（装置に貼ってあるラベルなど）

## UC-05 固有情報の欄を決める

- だれが: 装置担当
- すること: 装置ごとに、記録しておきたい項目（固有情報の欄）を定義
- 前提: ユーザーが入力するのは欄の値だけ。欄そのものは作らない
- 確認したいこと:
  - どの装置でどんな欄が必要か（温度、圧力、膜厚、測定条件など）
  - 欄を変更する頻度と、変更前に登録した実験データの見せ方
  - 装置担当が全装置の欄を決める形で問題ないか

## UC-06 製造の実験データを登録する

- だれが: ユーザー
- すること: 製造装置、試料（1つ）、実施日時を選び、固有情報、ファイル、説明を入力して登録。データ所有者は既定で自分
- 前提: 失敗、中断、やり直しも同じように登録
- 確認したいこと:
  - どこまでを1件の実験データとして扱うか（装置1台の1操作という区切りで合うか）
  - 1回の操作で複数の試料を扱う場面があるか。あれば試料ごとに1件ずつ登録する形で足りるか
  - 実施日時は装置の表示、手元のメモ、登録した時刻のどれを使うか
  - 固有情報を入力せずに登録する場面があるか
  - 登録者とデータ所有者が異なる場面（学生が登録して教員が所有者、装置担当が代行登録など）

## UC-07 検査の実験データを登録する

- だれが: ユーザー
- すること: UC-06 と同じ手順で、検査装置での作業を登録
- 前提: 同じ試料について、製造のあとに検査の実験データを続けて登録可
- 確認したいこと:
  - 製造と検査で、入力してもらう項目に違いを付けたいか
  - 1つの試料に対する製造と検査のおおよその回数

## UC-08 ファイルを添付する

- だれが: ユーザー
- すること: 実験データの登録時や訂正時に、ログや写真などのファイルを付ける。各ファイルは「データファイル」（ARIM RDE の構造化対象。装置ごとに拡張子が決まる）か「添付」のどちらか
- 確認したいこと:
  - よく付けるファイルの種類とおおよその大きさ
  - データファイルと添付の区分を、拡張子から自動で決めてよいか、ユーザーが選ぶか

## UC-09 実験データを訂正する

- だれが: その実験データを登録したユーザーだけ
- すること: 入力を間違えた実験データの内容を訂正
- 確認したいこと:
  - 登録した本人以外が代わりに直す必要があるか
  - 添付ファイルの差し替えや追加も訂正として扱うか
  - データ所有者の変更を訂正として扱う形で問題ないか

## UC-10 過去の記録を見る

- だれが: ユーザー（見られる範囲は確認したい）
- すること: 試料、装置、実施日などで検索し、最新の内容と訂正履歴を確認
- 確認したいこと:
  - 他のグループの記録を見られてよいか
  - よく使う探し方（試料名、装置、実施日、登録したユーザーなど）
