# ユースケース フェーズ1 — 本システムへの登録

全体の一覧は [use-cases.md](use-cases.md)。ここでは、実験者が装置の前で実験データを本システムに残すまでの場面を並べる。

## このフェーズに共通すること

- 本システムに登録した実験データが正式な記録（正本）
- 登録した実験データは削除できない。誤りは訂正して直す
- 訂正後は、最新の内容が正式な記録。前の内容は訂正履歴に残る
- 試料は1つのグループに属する。実験データは1つまたは複数の試料を指定可能
- 複数の試料を指定するときは、同じグループの試料だけ
- 固有情報と添付ファイルは空欄でも登録可

## UC-01 グループに所属する

- だれが: 実験者
- すること: 1つ以上のグループに所属し、試料作成時にグループを選択
- 確認したいこと:
  - グループの単位は研究室か、部署か、別の区切りか
  - 所属の追加や離脱をだれが行うか（本人、同じグループの実験者、運用担当の実験者など）

## UC-02 試料を作る

- だれが: 実験者
- すること: グループを選び、試料名を付けて試料を作成。化学式・組成式・分子式は空欄でも可
- 前提: 同一グループ内における試料名はユニーク
- 確認したいこと:
  - 現場で使っている試料名の付け方
  - 組成は試料作成時に必須か、後から入力でもよいか

## UC-03 試料の内容を直す

- だれが: その試料を作った実験者、またはその試料を使って実験データを登録した実験者
- すること: 試料の組成や名称などの誤りを訂正
- 確認したいこと:
  - 「作った人と使った人だけが直せる」で現場は足りるか
  - 同じグループの他の実験者にも訂正を許したい場面があるか

## UC-04 装置を台帳に登録する

- だれが: 装置担当
- すること: 製造装置か検査装置かを決めて、装置を台帳に登録
- 前提: 台帳はシステム全体で1つ。1台の装置は主な用途でどちらか一方の種別
- 確認したいこと:
  - 装置の追加、名称変更、使用終了を装置担当が行う形で問題ないか
  - 現場で通じる装置の呼び名（装置に貼ってあるラベルなど）

## UC-05 固有情報の欄を決める

- だれが: 装置担当
- すること: 装置ごとに、記録しておきたい項目（固有情報の欄）を定義
- 前提: 実験者が入力するのは欄の値だけ。欄そのものは作らない
- 確認したいこと:
  - どの装置でどんな欄が必要か（温度、圧力、膜厚、測定条件など）
  - 欄を変更する頻度と、変更前に登録した実験データの見せ方
  - 装置担当が全装置の欄を決める形で問題ないか

## UC-06 製造の実験データを登録する

- だれが: 実験者
- すること: 製造装置、試料（1つ以上）、実施日時を選び、固有情報と添付ファイルを入力して登録
- 前提: 失敗、中断、やり直しも同じように登録
- 確認したいこと:
  - どこまでを1件の実験データとして扱うか（装置1台の1操作という区切りで合うか）
  - 実施日時は装置の表示、手元のメモ、登録した時刻のどれを使うか
  - 固有情報を入力せずに登録する場面があるか

## UC-07 検査の実験データを登録する

- だれが: 実験者
- すること: UC-06 と同じ手順で、検査装置での作業を登録
- 前提: 同じ試料について、製造のあとに検査の実験データを続けて登録可
- 確認したいこと:
  - 製造と検査で、入力してもらう項目に違いを付けたいか
  - 1つの試料に対する製造と検査のおおよその回数

## UC-08 ファイルを添付する

- だれが: 実験者
- すること: 実験データの登録時や訂正時に、ログや写真などのファイルを添付
- 確認したいこと:
  - よく添付するファイルの種類とおおよその大きさ
  - ARIM RDE に送るときの必須ファイルと、この添付を分けて考えられるか

## UC-09 実験データを訂正する

- だれが: その実験データを登録した実験者だけ
- すること: 入力を間違えた実験データの内容を訂正
- 確認したいこと:
  - 登録した本人以外が代わりに直す必要があるか
  - 添付ファイルの差し替えや追加も訂正として扱うか

## UC-10 過去の記録を見る

- だれが: 実験者（見られる範囲は確認したい）
- すること: 試料、装置、実施日などで検索し、最新の内容と訂正履歴を確認
- 確認したいこと:
  - 他のグループの記録を見られてよいか
  - よく使う探し方（試料名、装置、実施日、登録した実験者など）
